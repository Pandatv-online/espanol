# Спецификация: грамматика и стиль как на старых страницах

## Задача

Грамматика на сайте выглядит «как скучная книга»: разделы сплошным текстом идут друг под другом. У автора есть
свои страницы по грамматике (`archive/*.html`) с живой структурой: тёмно-синяя шапка, нумерованные вкладки
(«1 Когда · 2 Фразы · 3 Спряжение…»), мини-вкладки внутри (Perfecto / Indefinido у каждого глагола), карточки-триггеры,
цветные метки-маркеры, строки примеров. Автор хочет, чтобы весь сайт выглядел так же, чтобы грамматика была устроена так же
и была подробнее, с большим количеством примеров, и чтобы на странице уровня грамматика шла раньше слов.

## Решение

- Весь сайт переходит на визуальный язык старых страниц: палитра (тёмно-синий, янтарь, бирюза, коралл, фиолетовый на бумажном фоне),
  шрифты Playfair Display + Noto Sans, шапка-hero, нумерованная полоса вкладок, карточки. Логотип сайта и «ступеньки» выбора
  уровня сохраняются — перекрашиваются в новую палитру, но остаются теми же по форме и поведению.
- Тёмная тема остаётся (авто по системе + кнопка) — тёмный вариант той же палитры.
- Каждая из 28 тем грамматики — страница как в старых файлах: hero с названием, полоса из 4–6 нумерованных вкладок по смыслу
  темы плюс последняя вкладка «Тест». Внутри вкладок — типовые блоки старых страниц: правила-карточки, триггеры,
  таблицы спряжения с мини-вкладками (выбор времени/наклонения/лица), маркеры-метки, примеры, подсказки-шпаргалки.
- Каждая тема подробнее старых страниц: 20–40 примеров на тему, у каждого перевод на язык интерфейса.
- На странице уровня: сначала «Грамматика», потом «Слова».
- verzo.pro в футере — обычная текстовая ссылка, без кнопки/плашки.
- Экраны слов (карточки, тест, список) — в том же стиле, поведение не меняется.

### Проход по глубине

- **First run / Empty:** тема без какой-то вкладки не показывает пустую вкладку — вкладок столько, сколько есть в данных.
- **Wrong input:** адрес с несуществующей вкладкой → первая вкладка темы, без ошибки.
- **Interruption:** незаконченный тест во вкладке ничего не записывает (как сейчас); переключение вкладок посреди теста не сбрасывает его, пока адрес темы тот же.
- **Growth:** схема блоков расширяема; валидатор знает все типы блоков.
- **Boundaries / Aftermath / Failure:** не применимо — статический сайт, поведение хранилища прежнее.

## Решения по реализации

1. **Данные темы грамматики — новая схема «вкладки из блоков»** (заменяет `sections`). Почему: структура старых страниц — это вкладки с типовыми блоками; схема повторяет её, чтобы контент задавал форму, а экран только рисовал.
2. **Один рендерер блоков в `js/views/grammar.js`**, стили в `css/grammar.css`. Почему: 28 тем одного образца.
3. **Палитра и шрифты старых страниц — в токенах `css/base.css`** (светлая и тёмная); компоненты сайта (ступеньки, логотип, карточки тем, кнопки) перекрашиваются токенами.
4. **Тест — служебная последняя вкладка**, строится из `quiz` темы, в данных отдельной вкладкой не описывается.
5. **Прежние ключи прогресса (`grammar:<id>`) и id тем не меняются** — накопленный прогресс учеников сохраняется.
6. **Сборка ведётся субагентами** (R12): по таску на контекст, ревью отдельными субагентами, контентные таски параллельно волнами.
7. **Ярус и число тасков.** Продукт — стиль + движок вкладок + контент; тасков 9, больше потолка T2 (8), потому что контент 28 тем в новом формате — большой объём текста, который не помещается в меньшее число контекстов (≈ 5 тем на таск).

### Схема темы грамматики (новая)

```js
{ id: 'a2-perfecto-indefinido', level: 'A2',
  title: { ru, en },                 // «Perfecto vs Indefinido»
  hero: { es: 'Pretérito Perfecto vs Indefinido', sub: { ru, en } },
  tabs: [
    { id: 'diff', label: { ru: 'Разница', en: 'Difference' },
      blocks: [
        { type: 'text',     body: { ru: ['…'], en: ['…'] } },                           // <b><i><em><strong><br>
        { type: 'rules',    items: [ { color: 'blue'|'amber'|'teal'|'coral'|'purple',
                                        title: { ru, en }, body: { ru, en }, es?: '…' } ] },
        { type: 'triggers', items: [ { num: 'W', title: { ru, en }, sub: { ru, en },
                                        phrases: ['quiero que', 'espero que'] } ] },
        { type: 'conj',     verbs: [ { inf: 'hablar', tr: { ru, en },
                                        variants: [ { label: 'Perfecto', color: 'blue',
                                                      rows: [['yo', 'he hablado'], …] },
                                                    { label: 'Indefinido', color: 'amber', rows: [...] } ] } ] },
        { type: 'table',    head: [...], rows: [[...]] },                               // ячейки ≤ 30 символов
        { type: 'markers',  groups: [ { color, title: { ru, en }, tags: ['hoy', 'esta semana'] } ] },
        { type: 'examples', items: [ { es: 'Hoy <b>he comido</b> paella.', ru, en } ] }, // <b> выделяет форму
        { type: 'tip',      title: { ru, en }, body: { ru, en } }                        // шпаргалка / мнемоника
      ] } ],
  quiz: [ …как сейчас… ] }
```

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `data` | реестр тем | без изменений | — |
| `grammar view` (`js/views/grammar.js`, `css/grammar.css`) | отрисовку темы по новой схеме | `ECA.views.register('grammar')`; `ECA.grammarBlocks.render(block, lang) -> Node` (для тестов); маршрут `#/<lvl>/grammar/<id>/<tab>` | разметку блоков, мини-вкладки |
| `validate` (`tools/validate-content.js`) | проверку схемы | валидирует `tabs/blocks` всех типов, id вкладок уникальны, ≥ 4 вкладок, ≥ 20 примеров, ячейки ≤ 30 символов, у `conj` ≥ 2 варианта, разрешённые теги | правила |
| `base.css` | токены светлой/тёмной темы старой палитры и базовые компоненты | CSS-переменные, классы компонентов | — |

Швы для тестов: `validate` (node --test), `grammarBlocks.render` (node --test с минимальным DOM или проверка в e2e), e2e по реальной странице.
