## Критерии приёмки

- [ ] Существительные-лица с парой по роду — один формат во всех уровнях: «el X / la Y», если формы различаются; «el/la X» для общего рода. В ru-переводе пара по роду тоже в одном формате (например «гражданин / гражданка»), а запятая — только между синонимами.
- [ ] Пометка латиноамериканского варианта — один шаблон во всех уровнях: ru «(в Лат. Америке — X)», en «(Latin America: X)» (el piso и другие отклонения приведены к нему); добавлены пропущенные: el portátil (la laptop), la chaqueta (в Мексике — la chamarra).
- [ ] Глагольные записи переводятся глагольным выражением в ru и en, без обрывков («felicitar» — без «wish happy…»).
- [ ] Ни один ru/en-перевод не длиннее ~60 символов: длинные пояснения (ложные друзья, лат.-ам. варианты) сокращены до сути, подробности — в `ex`. Для ложных друзей ru-пометка понятна русскоязычному («как англ. …» или путаница, правдоподобная для русского). molestar: «домогаться» — это acosar.
- [ ] c2-look-alikes: у каждой записи темы есть двойник (el porqué — с парой porque/por qué или заменён).
- [ ] vocab-b1 trabajador/a: EN-пример без навязанного рода (He/She или нейтрально).
- [ ] Внутри одной темы нет двух записей с совпадающим или синонимичным переводом (без скобок) ни в ru, ни в en.
- [ ] Эти правила записаны в `CONTENT.md` коротким списком «Как записывать».
- [ ] Количество записей в каждой теме не изменилось (13–15); `node tools/validate-content.js` и `node --test tests/` зелёные.
