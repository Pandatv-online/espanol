## Что должно заработать

То же поведение для пользователя, но без дублей: экраны слов и грамматики пользуются одним ходом теста,
одним генератором случайных чисел с сидом и одним правилом «где работают клавиши». Тесты проверяют свойства,
а не формулировки или конкретную перестановку. Плюс две видимые мелочи.

## Из брифа, дословно

> «интерактивный сайт для изучения испанского языка»
> «Максимально простой и в то же время понятный»

## Разделы спецификации

Истории 27–37, 49; «Границы и швы». `interfaces.md` — разделы «Из таска 02», «Из таска 03».

## Критерии приёмки

- [ ] Ход теста (сейчас `ECA.vocabQuiz` в `js/views/vocab.js`) и генератор с сидом (три копии: vocab.js, grammar.js, тесты) живут в `js/quiz.js` рядом с `ECA.quiz` под нейтральными именами; экраны слов и грамматики пользуются ими; `js/views/grammar.js` не зависит от `js/views/vocab.js`. `ECA.grammarQuiz` оставить только в той части, что специфична для грамматики.
- [ ] Правило «клавиши (стрелки, 1–4, Enter) работают, только когда фокус внутри колоды/теста, на `body` или на `h1` экрана» — одна функция в `ECA.ui`, её вызывают оба экрана.
- [ ] Без `ECA.quiz` колода не молча остаётся неперемешанной, а падает с понятной ошибкой.
- [ ] Тест перемешивания `fromGrammar`: падает, если варианты не переставляются (в данных верный ответ часто на позиции 0). В `CONTENT.md` одной строкой: варианты перемешиваются на экране, позиция `answer` в данных значения не имеет.
- [ ] `tests/vocab.test.js` проверяет контракт колоды (ровно невыученные слова, другой rng — другой порядок, know/again), а не конкретную перестановку; `tests/grammar.test.js` «порядок переживает смену языка» проверяет именно это: `fromGrammar` с одним сидом в ru и en даёт один порядок; `tests/content-c2.test.js` проверяет свойство (в одной теме нет записей с одинаковым переводом без скобок — для всех тем всех уровней), а не формулировки.
- [ ] e2e «each topic opens cleanly» ждёт отрисовки именно этой темы (h1 = её title) перед проверкой; `--shots` без каталога завершается с ошибкой.
- [ ] «Новый рекорд» показывается только когда был прошлый результат и он побит; первая попытка — только «Лучший результат: x из y».
- [ ] Кнопка темы: значок и подпись не противоречат друг другу в обеих темах.
- [ ] `node --test tests/`, `node tools/validate-content.js`, e2e — зелёные; поведение для пользователя не изменилось (кроме двух пунктов выше).
