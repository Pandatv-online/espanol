# Спецификация: Español con amigos — сайт для изучения испанского

## Задача

Человек учит испанский, а говорит по-русски или по-английски. Ему нужно одно простое место, где можно
выбрать свой уровень (A1–C2), открыть тему, погонять слова карточками, проверить себя тестом
и прочитать понятное объяснение грамматики на своём языке. Он не хочет регистрироваться,
разбираться в меню и начинать с нуля при каждом заходе. Автор Telegram-канала
«Español con amigos» хочет, чтобы с сайта люди приходили в канал за учебными материалами.

## Решение

Одностраничный статический сайт «Español con amigos» на чистых HTML/CSS/JS, готовый к GitHub Pages
и открывающийся двойным кликом по `index.html`.

- Сверху — название, переключатель RU/EN и переключатель темы ☀/☾.
- На главной — шесть кнопок уровней A1…C2 с подсказкой «что умеет человек на этом уровне».
  Выбран всегда ровно один уровень; показываются только его темы.
- У каждого уровня два раздела: **Слова** (8–10 тем) и **Грамматика** (4–5 тем).
- Тема слов: карточки (испанское слово → перевернул → перевод) с кнопками «Знаю» / «Повторить»,
  тест на 10 вопросов с вариантами ответа и список всех слов темы.
- Тема грамматики: объяснение (текст, таблицы, примеры) и тест с вариантами.
- Прогресс (выученные слова, лучший результат тестов, уровень, язык, тема) хранится в браузере.
- В футере — кнопка Telegram-канала «Español con amigos» с подписью про учебные материалы,
  строка «Сайт сделал verzo.pro» и «Сбросить прогресс».

Путь от входа до карточек — три действия: уровень → тема → карточки (R04).

### Про истории с меткой `R##.n`

Это проработка требований из брифа (глубина «максимальная»): поведение при первом заходе, ошибках, прерываниях, на телефоне, с клавиатуры. Новых возможностей (`A##`) в спецификации нет.

### Проход по глубине — что сознательно «не применимо»

- **Boundaries** (кто что может): аккаунтов и ролей нет, все видят одно и то же — не применимо, кроме R20i.2.
- **Growth**: 700 слов и 27 тем грузятся одним разом (≈ 200–300 КБ текста) — приемлемо; при росте в разы данные можно грузить по уровню — не сейчас.
- **Failure сети**: сайт статический, после загрузки сеть не нужна; внешняя зависимость одна — Google Fonts (история 16).

## Решения по реализации

1. **Одна страница, hash-роутинг.** Почему: работает и на `file://`, и на GitHub Pages без настройки 404; «назад» в браузере работает.
2. **Классические скрипты с общим пространством имён `window.ECA`, без ES-модулей.** Почему: модули не грузятся с `file://` в Chrome (R06.1).
3. **Контент — JS-файлы данных, по файлу на уровень и раздел** (`data/vocab-a1.js`, `data/grammar-a1.js`, …), каждый вызывает `ECA.data.addVocab(...)`/`addGrammar(...)`. Почему: `fetch` JSON на `file://` не работает, а файл на уровень держит правки автора локальными.
4. **Тексты интерфейса — словарь RU/EN в одном модуле.** Переводимые поля данных — объекты `{ru, en}`.
5. **Хранение — `localStorage`, один ключ `eca:v1`** с JSON; версия в ключе позволяет сменить схему позже.
6. **Логика без DOM (квиз, выбор языка, хранилище, валидация данных) пишется так, чтобы её можно было загрузить в Node** — для тестов `node --test` без сторонних пакетов.
7. **Проверка интерфейса — Playwright только как инструмент разработки** (в `tools/`, в сайт не входит).
8. **Шрифты — Google Fonts с `display=swap`** и системными fallback; иконки — inline SVG.
9. **Экранирование:** всё содержимое данных вставляется через `textContent`; разметка допускается только в полях объяснений грамматики, и только из ограниченного набора (`<b> <i> <em> <strong> <br>`), который рендерер проверяет.
10. **Дизайн:** направление выбирает исполнитель дизайна по скиллу `frontend-design`; ограничения — светлая и тёмная тема через CSS-переменные, контраст текста ≥ 4.5:1, мобильная вёрстка от 320px, не стиль старых страниц.

```js
  title: { ru: '…', en: '…' }, summary: { ru: '…', en: '…' },
  sections: [ { heading: { ru, en },
                body: { ru: ['абзац', …], en: ['paragraph', …] },            // допустимы <b><i><em><strong><br>
                table: { head: ['', 'hablar', …], rows: [['yo', 'hablo', …]] },  // необязательна, испанский
                examples: [ { es, ru, en } ] } ],                             // необязательны
  quiz: [ { prompt: { ru, en },          // задание: «Выберите форму»
            es: 'Ayer ___ (comer, yo) paella.',   // испанская часть вопроса, может отсутствовать
            options: ['comí', 'comía', 'he comido'], answer: 0,
            explain: { ru, en } } ] }
```

Идентификатор слова в прогрессе — `topicId + '|' + es`; `es` уникален внутри темы (проверяет валидатор).

### Маршруты

| Адрес | Экран |
|---|---|
| `#/` или пусто | уровень из хранилища (или A1) |
| `#/a1` … `#/c2` | уровень: подсказка, прогресс, разделы «Слова» и «Грамматика» |
| `#/a1/words/<topicId>` | тема слов: вкладки «Карточки», «Тест», «Список слов» |
| `#/a1/words/<topicId>/quiz` | тест темы слов |
| `#/a1/grammar/<topicId>` | тема грамматики: объяснение и тест |
| что угодно другое | «Такой страницы нет» + «К уровню» |

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `data` (`js/data.js`) | реестр уровней и тем | `ECA.data.addLevels(levels)`, `addVocab(level, topics)`, `addGrammar(level, topics)`, `levels() -> Level[]`, `vocab(level) -> Topic[]`, `grammar(level) -> Topic[]`, `find(kind, topicId) -> Topic\|null` | порядок регистрации, индексы |
| `i18n` (`js/i18n.js`) | язык интерфейса и строки | `ECA.i18n.detect(languages[]) -> 'ru'\|'en'`, `lang()`, `setLang(l)`, `t(key, params?) -> string`, `pick({ru,en}) -> string`, `onChange(fn)` | словарь строк, подстановку параметров |
| `store` (`js/store.js`) | всё, что лежит в `localStorage` | `ECA.store.available -> bool`, `pref(key)`, `setPref(key, val)` (`lang`, `theme`, `level`), `isLearned(topicId, es)`, `setLearned(topicId, es, bool)`, `learnedCount(topicId, words[])`, `best(quizKey) -> {score,total}\|null`, `recordScore(quizKey, score, total)`, `resetProgress()` | ключ `eca:v1`, JSON, try/catch, восстановление после порчи |
| `quiz` (`js/quiz.js`) | составление вопросов, без DOM | `ECA.quiz.fromVocab(topic, levelTopics, {lang, count=10, rng}) -> Question[]`, `ECA.quiz.fromGrammar(topic, {lang, rng}) -> Question[]`, `ECA.quiz.shuffle(arr, rng)`; `Question = {prompt, es?, options[], answer, explain?, promptLang}` | выбор отвлекающих вариантов, направление вопроса |
| `app` (`js/app.js` + `js/views/*.js`) | DOM, роутинг, тема оформления | `ECA.app.start()` | всё остальное |
| `validate` (`tools/validate-content.js`) | проверку данных | CLI: `node tools/validate-content.js` → код 0 / 1 и список ошибок; `validate(ECA.data) -> errors[]` | правила проверки |

**Швы для тестов:** `quiz`, `i18n.detect`, `store` (с подменой `localStorage`) и `validate` — через `node --test`; поведение интерфейса — Playwright по реальной странице (`tools/e2e.spec.js`), только как проверка сборки.

Загрузка в Node: каждый модуль — IIFE вида `(function (root) { … })(typeof window !== 'undefined' ? window : globalThis)`, регистрирующий себя в `root.ECA`; тест делает `require` файла и читает `globalThis.ECA`.
