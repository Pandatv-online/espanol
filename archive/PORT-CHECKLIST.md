# Перенос старых страниц грамматики

Перечень содержимого пяти старых страниц из `archive/` и куда каждый пункт перенесён.
Темы: `a2-perfecto-indefinido`, `a2-imperfecto` (`data/grammar-a2.js`),
`b1-imperativo-pronombres`, `b1-subjuntivo-presente` (`data/grammar-b1.js`).
Раздел указан по русскому заголовку. Русский текст взят из оригинала (местами сокращён), английский — перевод.

Общее для всех пяти файлов — **не перенесено, причина: оформление, а не содержание**:
шапка с флагом 🇪🇸, вкладки-навигация и их скрипт (`showTab`, `switchConj`), подпись в футере
(«Создано PandaGroup / с помощью Claude»), цветовые метки P / I / IND / SUB / AFIRM / NEG
(заменены словами в переводе примера или стрелкой «→»).
