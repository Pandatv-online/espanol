# Индексация сайта

Публичный адрес сайта хранится в `tools/site-url.txt`. Он должен оканчиваться `/`.

После изменений в `data/` выполните:

```sh
node tools/validate-content.js
node tools/generate-discovery.js
node --test tests/
```

Генератор пересоздаёт каталог `learn/` с русскими и английскими HTML-страницами, а также `sitemap.xml`, `robots.txt`, `llms.txt` и `llms-full.txt`. Не редактируйте `learn/` вручную. Все эти файлы нужно публиковать вместе с `index.html` и `css/reading.css`. Если адрес сайта изменится, обновите `tools/site-url.txt`, canonical и `og:url` в `index.html`, затем запустите генератор снова.

После публикации проверьте, что `https://espanolconamigos.com/sitemap.xml` и несколько страниц из него открываются с HTTP 200, и отправьте карту сайта в Google Search Console и Яндекс Вебмастер. Карта сайта помогает обнаруживать страницы, но не гарантирует их индексацию.

Интерактивные адреса `#/...` продолжают работать; поисковые страницы в `learn/` показывают тот же учебный материал без JavaScript и ссылаются на упражнения.
