**Контекст**
В этом прогоне все 28 тем грамматики переписаны в новом формате (ADR 0007), а весь сайт перерисован (ADR 0008). Прогресс учеников хранится только в их браузере (ADR 0005): выученные слова по ключу `topicId|es`, лучшие результаты тестов по ключам `words:<id>` и `grammar:<id>`. Сервера, через который можно было бы перенести данные, нет. На темы ведут ссылки из Telegram-канала (ADR 0002).

**Решение**
Id всех тем и ключи прогресса при переделке не меняются. Структура хранилища остаётся прежней. Выбранная вкладка в ключ прогресса не входит: результат относится ко всей теме.

**Почему**
- Переименовать темы под новую структуру отвергнуто: ученики потеряли бы накопленные результаты, а ссылки из канала перестали бы открывать тему.
- Новая версия хранилища с переносом старых ключей отвергнута: это код, который выполняется у каждого ученика и который нельзя поправить задним числом, и всё это ради переименований, которые никому не нужны.
- Сбросить прогресс при смене дизайна отвергнуто: для ученика редизайн не повод начинать заново.

**Последствия**
- Лучший результат, полученный на тесте старой версии темы, засчитывается и после переделки, в том числе для отметки «✓ пройдено».
- Старые ссылки без вкладки продолжают работать и открывают первую вкладку темы.
- Id тем теперь фактически постоянны. Неудачное имя остаётся навсегда: переименование потребует миграции в хранилище и сломает внешние ссылки.
- Новые темы получают id с расчётом на то, что его не поменяют никогда.
