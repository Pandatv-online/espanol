# Как добавлять слова и грамматику

Весь учебный контент лежит в папке `data/`. Дизайн и код сайта трогать не нужно:
меняете файл данных, сохраняете, обновляете страницу в браузере.

## Где что лежит

| Файл | Что внутри |
|---|---|
| `data/levels.js` | шесть уровней A1–C2: название и строка «что умеет человек на этом уровне» |
| `data/vocab-a1.js` … `data/vocab-c2.js` | темы слов, по файлу на уровень |
| `data/grammar-a1.js`, `grammar-a2.js`, `grammar-a2-more.js`, `grammar-b1.js`, `grammar-b1-more.js`, `grammar-b2.js`, `grammar-c1.js`, `grammar-c2.js` | темы грамматики |

Каждый текст для ученика пишется на двух языках: `{ ru: '…', en: '…' }`.
Испанский текст (`es`) не переводится и одинаков для обоих языков.

## Как добавить слово

Откройте файл темы, например `data/vocab-a1.js`, найдите список `words: [ … ]` нужной темы
и добавьте строку перед закрывающей скобкой `]`:

```js
{ es: 'la casa', ru: 'дом', en: 'house',
  ex: { es: 'Mi casa es pequeña.', ru: 'Мой дом маленький.', en: 'My house is small.' } },
```

- `es` — слово по-испански. Существительные пишите **с артиклем**: `el libro`, `la casa`.
- `ru`, `en` — перевод.
- `ex` — пример (необязателен, но нужен хотя бы у половины слов темы).
- Одно и то же испанское слово в одной теме дважды быть не должно.
- Не забудьте запятую после `}`.

## Как добавить тему слов

В файле уровня (например `data/vocab-a2.js`) внутри `ECA.data.addVocab('A2', [ … ])`
добавьте объект темы. В теме должно быть **не меньше 12 слов**.

```js
ECA.data.addVocab('A2', [
  {
    id: 'a2-food',            // уникальный: уровень + тема латиницей, через дефис
    level: 'A2',              // тот же уровень, что в addVocab('A2', …)
    icon: '🍅',               // один эмодзи
    title: { ru: 'Еда', en: 'Food' },
    words: [
      { es: 'el pan', ru: 'хлеб', en: 'bread',
        ex: { es: 'Compro pan cada día.', ru: 'Я покупаю хлеб каждый день.', en: 'I buy bread every day.' } },
      { es: 'la leche', ru: 'молоко', en: 'milk' }
      // … ещё минимум 10 слов
    ]
  }
]);
```

Если в файле уже есть темы, новая добавляется через запятую после предыдущей `}`.

## Как добавить тему грамматики

В файле уровня (например `data/grammar-a2.js`) внутри `ECA.data.addGrammar('A2', [ … ])`.
Полный пример с объяснением, таблицей, примерами и тестом:

```js
ECA.data.addGrammar('A2', [
  {
    id: 'a2-gustar',
    level: 'A2',
    title: { ru: 'Глагол gustar', en: 'The verb gustar' },
    summary: { ru: 'Как сказать «мне нравится» по-испански.', en: 'How to say “I like” in Spanish.' },
    sections: [
      {
        heading: { ru: 'Как это устроено', en: 'How it works' },
        body: {
          ru: ['По-испански не «я люблю», а «мне нравится»: <b>me gusta</b> el café.',
               'Если нравится много предметов — <b>gustan</b>: me gustan los libros.'],
          en: ['In Spanish you say “it pleases me”: <b>me gusta</b> el café.',
               'For several things use <b>gustan</b>: me gustan los libros.']
        },
        table: {
          head: ['', 'una cosa', 'varias cosas'],
          rows: [
            ['a mí', 'me gusta', 'me gustan'],
            ['a ti', 'te gusta', 'te gustan']
          ]
        },
        examples: [
          { es: 'Me gusta el mar.', ru: 'Мне нравится море.', en: 'I like the sea.' }
        ]
      }
    ],
    quiz: [
      { prompt: { ru: 'Выберите форму', en: 'Choose the form' },
        es: 'Me ___ los perros.',
        options: ['gusta', 'gustan', 'gusto'],
        answer: 1,                                   // номер верного варианта, счёт с 0
        explain: { ru: 'Los perros — много, поэтому gustan.', en: 'Los perros is plural, so gustan.' } }
      // … всего 8–10 вопросов
    ]
  }
]);
```

Правила:

- В тексте объяснения (`body`) можно выделять: `<b>жирный</b>`, `<i>курсив</i>`, `<em>`, `<strong>`, перенос строки `<br>`. Остальные теги сайт покажет как обычный текст.
- `table` и `examples` необязательны. В таблице в каждой строке столько же ячеек, сколько в `head`.
- В тесте 8–10 вопросов, у каждого 3 или 4 варианта. `answer` — номер верного варианта, **считая с нуля**: первый вариант — `0`, второй — `1`.
- `es` в вопросе — испанская фраза с пропуском `___`; можно не указывать, если вопрос целиком в `prompt`.

## Как добавить новый файл данных

Если файл для уровня уже есть — пишите в него. Новый файл (например `data/grammar-b2-more.js`)
нужно подключить в `index.html` строкой `<script src="data/grammar-b2-more.js"></script>`
рядом с остальными файлами `data/`. Валидатор напомнит, если забыть.

## Как проверить себя

В папке сайта выполните:

```
node tools/validate-content.js
```

- `OK: …` — всё в порядке.
- Иначе будет список ошибок вида `A2 · a2-food · words[3].ru — пустое поле`:
  уровень, тема, поле (здесь — перевод у четвёртого слова, счёт с нуля) и что не так.

Проверяется: заполнены ли оба языка, уникальны ли `id` тем и испанские слова в теме,
хватает ли слов (≥ 12) и вопросов (8–10), есть ли 3–4 варианта ответа и указывает ли
`answer` на существующий вариант, совпадает ли `level` темы с файлом.

Тесты кода сайта (для разработчика): `node --test tests/`.
