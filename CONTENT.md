# Как добавлять слова и грамматику

Весь учебный контент лежит в папке `data/`. Дизайн и код сайта трогать не нужно:
меняете файл данных, сохраняете, обновляете страницу в браузере.

## Где что лежит

| Файл | Что внутри |
|---|---|
| `data/levels.js` | шесть уровней A1–C2: название и строка «что умеет человек на этом уровне» |
| `data/vocab-a1.js` … `data/vocab-c2.js` | темы слов, по файлу на уровень |
| `data/grammar-a1.js`, `grammar-a2.js`, `grammar-a2-more.js`, `grammar-b1.js`, `grammar-b1-more.js`, `grammar-b2.js`, `grammar-c1.js`, `grammar-c2.js` | темы грамматики |

Каждый текст для ученика пишется на двух языках: `{ ru: '…', en: '…' }`.
Испанский текст (`es`) не переводится и одинаков для обоих языков.

## Как добавить слово

Откройте файл темы, например `data/vocab-a1.js`, найдите список `words: [ … ]` нужной темы
и добавьте строку перед закрывающей скобкой `]`:

```js
{ es: 'la casa', ru: 'дом', en: 'house',
  ex: { es: 'Mi casa es pequeña.', ru: 'Мой дом маленький.', en: 'My house is small.' } },
```

- `es` — слово по-испански. Существительные пишите **с артиклем**: `el libro`, `la casa`.
- `ru`, `en` — перевод.
- `ex` — пример (необязателен, но нужен хотя бы у половины слов темы).
- Одно и то же испанское слово в одной теме дважды быть не должно.
- Не забудьте запятую после `}`.

## Как записывать слова

Чтобы все темы выглядели одинаково, а в тесте правильный ответ не выделялся среди вариантов:

- **Люди с парой по роду.** Если формы разные — `el camarero / la camarera`; если форма одна — `el/la turista`.
  В переводе пара тоже через косую черту: `официант / официантка`, `waiter / waitress`.
  Запятая — только между синонимами: `учитель, преподаватель`.
- **Латиноамериканский вариант** — в скобках после перевода: ru `(в Лат. Америке — el celular)`,
  en `(Latin America: el celular)`. Если слово только одной страны — её название: `(в Мексике — la chamarra)`, `(Mexico: la chamarra)`.
  В теме латиноамериканских слов наоборот: `(в Испании — el móvil)`, `(Spain: el móvil)`.
- **Глагол переводится глаголом** в обоих языках: `felicitar` — `поздравлять`, `to congratulate`, без обрывков вроде «wish happy…».
- **Перевод короткий — не длиннее ~60 символов.** Пояснения сводите к сути, подробности — в пример `ex`.
- **Ложные друзья:** `беременная (не «смущённая», как англ. embarrassed)` — русскому читателю нужна подсказка,
  откуда путаница: «как англ. …» или похожее русское слово (`не «актуальный» — это relevante`).
  По-английски: `pregnant (not 'embarrassed' — that's avergonzada)`.
- **В одной теме нет двух слов с одинаковым или синонимичным переводом** (пометки в скобках не в счёт):
  не `рука (кисть)` и `рука (от плеча)`, а `кисть руки` и `рука (от плеча до кисти)`.
- В теме «похожие слова» у каждого слова есть двойник, с которым его путают.

## Как добавить тему слов

В файле уровня (например `data/vocab-a2.js`) внутри `ECA.data.addVocab('A2', [ … ])`
добавьте объект темы. В теме должно быть **не меньше 12 слов**.

```js
ECA.data.addVocab('A2', [
  {
    id: 'a2-food',            // уникальный: уровень + тема латиницей, через дефис
    level: 'A2',              // тот же уровень, что в addVocab('A2', …)
    icon: 'bowl-food',        // имя иконки Phosphor, см. ниже
    title: { ru: 'Еда', en: 'Food' },
    words: [
      { es: 'el pan', ru: 'хлеб', en: 'bread',
        ex: { es: 'Compro pan cada día.', ru: 'Я покупаю хлеб каждый день.', en: 'I buy bread every day.' } },
      { es: 'la leche', ru: 'молоко', en: 'milk' }
      // … ещё минимум 10 слов
    ]
  }
]);
```

Если в файле уже есть темы, новая добавляется через запятую после предыдущей `}`.

### Иконка темы

Иконки — набор [Phosphor](https://phosphoricons.com) (стиль Duotone, лицензия MIT). В `icon` пишут имя иконки
с сайта, без стиля: `bowl-food`, `airplane-tilt`, `heart`. Сайт красит её в цвет карточки сам.

Новую иконку нужно один раз добавить в `js/icons.js`: после правки `data/` запустите `node tools/icons.js`
(нужен интернет — скрипт скачивает пакет `@phosphor-icons/core` через `npm pack`). Валидатор ругается, если имени
нет в `js/icons.js`, и подсказывает эту команду.

## Тема грамматики

Тема грамматики — это страница как в `archive/*.html`: шапка-hero, полоса нумерованных вкладок (`1 Разница · 2 Спряжение …`), внутри вкладок — типовые блоки. Последнюю вкладку «Тест» сайт добавляет сам из `quiz` — в `tabs` её **не описывают**. Эталон — тема `a2-perfecto-indefinido` в `data/grammar-a2.js`: открывайте её рядом, когда переводите свою.

Тема лежит в файле уровня (например `data/grammar-a2.js`) внутри `ECA.data.addGrammar('A2', [ … ])`.

### Верх темы

| Поле | Что это |
|---|---|
| `id` | уникален на всём сайте. **У существующей темы не менять** — по нему хранится прогресс (`grammar:<id>`) и строится адрес |
| `level` | совпадает с уровнем в `addGrammar('A2', …)` |
| `title {ru,en}` | название в списке тем уровня и во вкладке браузера |
| `hero.es` | большой заголовок страницы, испанский термин. `<b>…</b>` красит часть в янтарный (`Perfecto <b>vs</b> Indefinido`) |
| `hero.sub {ru,en}` | одна строка-подзаголовок под заголовком; её же видно в списке тем уровня. Простой текст: без тегов и без списка абзацев |
| `summary {ru,en}` | не нужен: в новом формате его заменяет `hero.sub` (если оставить — должен быть заполнен) |
| `tabs` | 4–6 вкладок до «Теста» |
| `quiz` | тест, как раньше — см. «Тест» ниже |

### Вкладка

`{ id, label: {ru, en}, blocks: [ … ] }`

- `id` — латиница, цифры, дефис (`diff`, `conj`, `irregulares`); уникален в теме; `test` занят «Тестом». Идёт в адрес: `#/a2/grammar/a2-perfecto-indefinido/conj`.
- `label` — короткая подпись, **не длиннее 12 символов** на каждом языке (`Разница`, `Неправильные`, `Markers`). Номер сайт ставит сам.
- `blocks` — непустой список блоков; блоки идут сверху вниз в заданном порядке.
- У любого блока можно указать `heading: {ru, en}` — маленький заголовок-разделитель над блоком (`СРАВНЕНИЕ ———`). Обычно нужен, когда во вкладке несколько блоков.

### Типы блоков

Цвет (`color`) везде один из пяти: `blue` (тёмно-синий), `amber` (янтарь), `teal` (бирюза), `coral` (коралл), `purple` (фиолетовый). В паре противопоставлений держите цвета постоянными по всей теме (у эталона Perfecto — всегда `blue`, Indefinido — всегда `amber`); подробно — в «Оформлении темы», правило 3.

Где сказано «текст с тегами», можно `<b> <i> <em> <strong> <br>` без атрибутов — и ничего больше. `{ru, en}` с текстом — это либо строка, либо список абзацев: `{ ru: ['абзац 1', 'абзац 2'], en: [...] }`.

| `type` | Поля | Как выглядит и когда брать |
|---|---|---|
| `text` | `body {ru,en}` текст с тегами; `color?` | Без `color` — обычные абзацы. С `color` — заметка с цветной полосой слева (как `rule-box` старых страниц): правило, подсказка, исключение. Одна мысль — одна заметка |
| `rules` | `items: [{ color, title {ru,en}, body {ru,en} текст с тегами, label? {ru,en}, es? }]` | Карточки-правила в сетке (2 в ряд на широком экране). `label` — надпись капсом над заголовком, `es` — формула-плашка (`haber + participio`). `blue` — тёмная карточка, остальные цвета — светлые |
| `triggers` | `items: [{ num, title {ru,en}, phrases: ['…'], sub? {ru,en}, body? {ru,en}, ex? {es,ru,en}, color? }]` | Пронумерованные карточки случаев употребления (WEIRDO: `num: 'W'`, `'E'` … или `'1'`, `'2'`). `phrases` — фразы-метки на испанском (минимум одна), `ex` — пример с формой в `<b>` |
| `conj` | `verbs: [{ inf, tr? {ru,en}, variants: [{ label, color, rows: [['yo', 'he hablado'], …] }] }]` | Карточка глагола с **мини-вкладками**: у каждого варианта своя вкладка (Perfecto / Indefinido, indicativo / subjuntivo, tú / usted, -ra / -se). Вариантов **не меньше 2**. `label` — строка на испанском (`'Perfecto'`) или `{ru, en}` (`{ ru: 'правильные', en: 'regular' }`), до 16 символов. `rows` — пары [местоимение, форма]; в форме можно выделить окончание `<b>`: `'habl<b>é</b>'`. Мини-вкладки переключают только свой глагол |
| `table` | `head: [...]`, `rows: [[...], …]` | Таблица с тёмной шапкой. Ячейка — строка на испанском **или** `{ru, en}` для текста на языке интерфейса. **Каждая ячейка ≤ 30 символов** — объяснения пишите в `text`, в таблице только короткие формы и слова. В каждой строке столько же ячеек, сколько в `head`. Если `head[0]` — пустая строка `''`, первая колонка становится заголовками строк. Широкая таблица прокручивается внутри себя |
| `markers` | `groups: [{ color?, title {ru,en}, tags: ['hoy', 'ya', …] }]` | Коробки со словами-метками (маркеры времени, союзы, триггеры). `tags` — испанские слова/фразы, без пустых. Без `color` — нейтральная «бумажная» коробка: для групп, которые не относятся ни к одному цветному понятию темы |
| `examples` | `items: [{ es, ru, en, color?, badge? }]` | Строки «испанский — перевод». В `es` изучаемая форма **обязательно** в `<b>…</b>`. `color` красит выделенную форму; `badge` — короткая вертикальная метка (1–3 символа: `'P'`, `'I'`, `'ir'`) для примеров попарно |
| `tip` | `title {ru,en}`, `body {ru,en}` текст с тегами | Шпаргалка/мнемоника в пунктирной янтарной рамке. Одна-две на тему, обычно в конце вкладки |

### Правила темы

- **Вкладок 4–6** (без «Теста»). Какие — по «Карте вкладок» спецификации; вкладку можно объединить или разделить, если материал требует.
- **Примеров 20–40** на тему (валидатор требует ≥ 20). Считаются только элементы блоков `type: 'examples'` во всех вкладках; примеры внутри `triggers` не входят в счёт.
- Примеры разные по лицам (yo, tú, él, nosotros, vosotros, ellos) и ситуациям (дом, работа, путешествия, друзья). Перевод — естественный, на обоих языках.
- **Мини-вкладки** (`conj`) — везде, где у формы есть выбор: два времени, два наклонения, правильные / неправильные, формы -ra / -se. Если выбор не спряжение, а «одна фраза в двух вариантах», это тоже `conj`: `inf` — фраза или ключевое слово, `rows` — пары [подпись, вариант].
- **Маркеры и фразы-триггеры** — метками (`markers` или `phrases` в `triggers`), а не списком через запятую в тексте.
- **Переводя старую тему (`sections`)**: всё, что было в её разделах, должно оказаться во вкладках — правила, таблицы, примеры, исключения. Если тема есть в `archive/PORT-CHECKLIST.md`, сверяйтесь с её строками: ни одна не должна потеряться. Тест (`quiz`) переносится как есть, `id` не меняется. Поле `sections` удаляется целиком: старый формат валидатор больше не принимает.
- Всё, что зависит от языка интерфейса, — в `{ru, en}`: подписи, заголовки, объяснения, ячейки-критерии. Испанский — просто строкой.
- **В испанских полях — только испанский**: `hero.es`, `es` у правил и примеров, `ex.es`, `phrases`, `tags`, `inf` и `rows` в `conj`, строковые ячейки таблиц. Кириллица там — ошибка валидатора (на английском интерфейсе её было бы видно по-русски). Пояснение по-русски пишется в `{ru, en}`.

### Оформление темы

Все темы оформлены по одним правилам — так ученик на любой теме сразу понимает, что где.

1. **id вкладок — английские слова**: `gender`, `conj`, `irreg`, `use`, `examples` (не `genero`, `ejemplos`).
2. **Подписи вкладок — полные слова** на обоих языках, без сокращений: «Утверждение» / «Affirmative», а не «Afirm.». До 12 символов.
3. **Цвета.**
   - (а) В одной мини-вкладке `conj` и в одной паре противопоставлений у вариантов **разные** цвета (Perfecto — `blue`, Indefinido — `amber`).
   - (б) **Внутри темы один цвет = одно значение.** Если `teal` — Imperfecto, то `teal` нигде в теме не значит другое. Цветная заметка берёт цвет того понятия, о котором она; общая заметка (про ударение, орфографию) — без `color`. Карточки-перечисления одного понятия (случаи употребления, группы фраз) — одним цветом этого понятия.
   - (в) По сайту, где это не спорит с (а) и (б): Indefinido — `amber`, Imperfecto — `teal`, Subjuntivo — `coral`. Единой карты «время → цвет» нет: в паре Futuro / Condicional цвета всё равно разные.
4. **Заголовки строк таблиц короткие**: `yo, tú, él / ella, nosotros, vosotros, ellos` — без «/ usted», «/ nosotras». Таблица в 4 колонки должна помещаться в экран телефона (около 340 px): в ячейках только короткие формы.
5. **Мини-вкладки — выбор формы одного глагола** (или одной фразы): Perfecto / Indefinido, indicativo / subjuntivo, «yo» / «другие лица». Разные глаголы — отдельными карточками в одном блоке `conj`, а не мини-вкладками одной карточки. Три образца рядом (hablar · comer · vivir) — таблицей.
6. **Без повторов и перегруза.** Парадигма глагола показана в теме один раз; пример не повторяется в разных вкладках. Во вкладке не больше ~6 блоков: тяжёлую вкладку разделите или перенесите примеры в «Примеры». Основная масса примеров — во вкладке «Примеры».
7. **Заголовки блоков.** Если во вкладке два и больше блоков одного типа (кроме `text` и `tip`), у каждого из них есть `heading` — иначе их не различить. Одиночному блоку своего типа `heading` можно не ставить (так у эталона). В темах A1–B1 (кроме эталона) `heading` стоит у всех блоков, кроме `text` и `tip`, во вкладке из нескольких блоков — так и пишите новые темы.

### Тест

- 8–10 вопросов, у каждого 3 или 4 варианта. `answer` — номер верного варианта, **считая с нуля**: первый вариант — `0`, второй — `1`. Варианты на экране перемешиваются, поэтому позиция верного ответа в данных значения не имеет — можно всегда ставить его первым.
- `es` в вопросе — испанская фраза с пропуском `___`; можно не указывать, если вопрос целиком в `prompt`.
- `explain {ru,en}` — почему так; текст с тегами.

## Как добавить новый файл данных

Если файл для уровня уже есть — пишите в него. Новый файл (например `data/grammar-b2-more.js`)
нужно подключить в `index.html` строкой `<script src="data/grammar-b2-more.js"></script>`
рядом с остальными файлами `data/`. Валидатор напомнит, если забыть.

## Как проверить себя

В папке сайта выполните:

```
node tools/validate-content.js
```

- `OK: …` — всё в порядке.
- Иначе будет список ошибок вида `A2 · a2-food · words[3].ru — пустое поле`:
  уровень, тема, поле (здесь — перевод у четвёртого слова, счёт с нуля) и что не так.

Проверяется: заполнены ли оба языка, уникальны ли `id` тем и испанские слова в теме,
хватает ли слов (≥ 12) и вопросов (8–10), есть ли 3–4 варианта ответа и указывает ли
`answer` на существующий вариант, совпадает ли `level` темы с файлом.

Тесты кода сайта (для разработчика): `node --test tests/`.
